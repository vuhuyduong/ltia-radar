2 Khắc phục Sự cố MongoDB Atlas & Triển khai Container MongoDB Local

Nguyên nhân Sự cố Cũ

  • Cluster MongoDB Atlas cũ (ltia-radar.h7bibjh.mongodb.net) không còn bản ghi DNS SRV (NXDOMAIN), gây lỗi 500 Internal Server Error trên toàn bộ API khi mới chuyển về local.
  • Bản ghi llm_configs mặc định do seed.py khởi tạo có trường api_key: "" (rỗng), vô tình che khuất biến môi trường GEMINI_API_KEY.

Giải pháp Đã Thực hiện

  • Bổ sung container ltia-mongodb-local (image mongo:7.0, healthcheck tự động, volume bền vững ltia-mongo-local-data) vào docker-compose.localbackend.yml.
  • Cập nhật MONGODB_URI=mongodb://mongodb:27017 trong .env.localbackend.
  • Sửa GeminiImplementation._load_config() để luôn kết hợp cả danh sách key hoạt động trong DB lẫn key dự phòng trong .env, loại bỏ hoàn toàn lỗi chuỗi rỗng.
3 Quản trị Hạn mức Google AI Studio Free Tier & Xoay vòng Khóa (Gemini 3.8 Flash · Effort High)

Bộ Điều tiết KeyPool Toàn Tiến trình (backend/app/infrastructure/llm/quota.py) Singleton Process-Wide

  • Cố định mô hình chuẩn: Toàn bộ luồng phân tích đơn lẻ và gom cụm theo lô luôn sử dụng gemini-3.8-flash với cấu hình types.ThinkingConfig(thinking_level=types.ThinkingLevel.HIGH).
  • Kiểm soát trượt 3 chiều (Sliding-Window Rate Limiter): Theo dõi riêng từng API Key theo hạn mức Free Tier: RPM = 5 req/phút, TPM = 250.000 token/phút, RPD = 20 req/ngày.
  • Tự động nhận diện Reset nửa đêm Pacific: Khi gặp lỗi 429 RESOURCE_EXHAUSTED kèm quota ngày (PerDay), tự động khóa tạm thời key đó đến 00:00 America/Los_Angeles (14:00 giờ Việt Nam) và chuyển tức thì sang key khả dụng tiếp theo.
  • Phân biệt lỗi 429 (Quota) và 503 (Server Overloaded): Khi gặp 503 UNAVAILABLE, thực hiện Exponential Backoff + Jitter mà không phạt oan hạn mức RPD của key.
  • Cơ chế dừng an toàn QuotaExhausted: Khi toàn bộ key đều chạm trần ngày, dừng chu kỳ gọi LLM êm ái; các bài báo mới trong raw_data được bảo toàn để tự động phân tích tiếp ở chu kỳ sau.
  • Giao diện & API đồng bộ nhanh nhiều Key: Bổ sung ô "Nạp nhanh danh sách API Key Gemini (Xoay vòng)" trên trang Quản trị và API POST /api/llm-configs/gemini-keys/sync.
